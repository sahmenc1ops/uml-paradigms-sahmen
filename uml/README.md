# Library Management System — UML Diagrams

## 1. Use Case Diagram

The Use Case Diagram shows the main actors who interact with the Library Management System and the actions they can perform. It gives an overview of the system's main functionalities, such as borrowing and returning books.

## 2. Class Diagram

The Class Diagram represents the main classes of the Library Management System, including Library, Book, Member, Librarian, and Loan. It shows their attributes, operations, relationships, and multiplicities.

## 3. Sequence Diagram

The Sequence Diagram shows the order of interactions when a member borrows a book. It illustrates how the Member, Librarian, Book, and Loan objects communicate during the borrowing process.

## 4. Activity Diagram

The Activity Diagram represents the workflow for borrowing a book. It shows the steps from requesting a book and checking its availability to creating a loan and confirming the borrowing.
